1. Установка модулей и зависимостей

Прежде чем работать с проектом нужно установить все необходимые пакеты
    cmd\bash `go mod tidy`

Установка AIR для обновления в реальном веремени
    cmd\bash `go install github.com/air-verse/air@latest`

Установка golang-migrate для работы с миграциями базы данных, сама работа объясняется в пункте [4]
    cmd\bash `go install -tags 'postgres' github.com/golang-migrate/migrate/v4/cmd/migrate@latest`

2. База данных

Перед работой необходимо поднять базу данных PostgreSQL через pgAdmin. Имя базы даных, пароль, юзер, порт указаны в конфиг файле, учесть при скачке PostgreSQL там буду просить указать порт и юзер+пароль. Если уже был установлен PostgreSQL указать в конфиге свои данные

Важно! Если поменял данные в конфиге на свои не забудь поменять везде где используется строка подключения!
./internal/database/database.go ./Makefile

3. Запуск приложения

    cmd\bash `air`

4. Работа с Makefile и миграциями

В Makefile прописаны команды для работы с миграциями. Так например при создании новой таблицы или изменениях в старых таблицах используются миграции
